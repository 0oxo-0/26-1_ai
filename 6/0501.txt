
5월 1일 보강 정리

1. Dense / Fully Connected Network의 한계

이미지를 평탄화(flattening)하면 원래의 2차원 공간 구조가 사라진다.
그래서 픽셀 사이의 위치 관계, 주변 관계, 공간적 특징을 잘 반영하지 못한다.

예: 눈, 코, 입의 상대적 위치 / 가장자리, 모서리, 패턴

2. Convolution(합성곱)의 필요성

이 한계를 보완하기 위해 합성곱 연산을 사용한다.
합성곱은 이미지 전체를 한 번에 보는 대신, 작은 영역을 훑으면서 지역적 특징(local feature)을 추출한다.

3. 합성곱이란?

원본 이미지에 필터(filter, kernel)를 적용해서 새로운 특징맵(feature map)을 만드는 연산이다.

과정:
* 필터가 이미지 위를 이동
* 해당 부분과 곱셈/덧셈 계산
* 결과로 새로운 특징을 만든다

* 엣지(edge), 선, 모서리, 질감같은 특징을 추출한다.

4. Dense와 CNN의 차이

Dense:

* 입력과 출력이 전부 연결
* 이미지가 평탄화된 뒤 들어감
* 공간 구조를 잘 살리지 못함
* 가중치가 매우 많아질 수 있음

CNN:

* 입력의 일부 영역에만 필터를 적용
* 같은 필터를 여러 위치에 공유해서 사용
* 공간적 특징을 잘 잡음
* 필터 크기와 개수에 따라 파라미터 수가 결정됨


5. 합성곱 연산 후 정보량 증가

합성곱을 하면 여러 필터를 통해 여러 특징맵이 만들어질 수 있어서 처리해야 할 정보가 많아질 수 있다.

장) 특징은 잘 추출되지만
단) 계산량과 정보량이 커질 수 있음

6. 풀링(Pooling)의 필요성

합성곱 뒤에는 정보가 많아지므로 풀링을 통해 크기를 줄인다.

* feature map의 크기를 줄여서 계산량 감소, 중요한 특징만 요약


7. 풀링 종류

최대 풀링(Max Pooling)

* 영역 안에서 가장 큰 값을 선택

평균 풀링(Average Pooling)

* 영역 안의 평균값을 선택

8. 풀링의 역할 2가지

1) 정보 요약
중요한 특징만 남기고 전체 크기를 줄임

2) 이동에 대한 불변성
입력 이미지가 조금 이동해도
비슷한 특징을 유지하도록 도움
즉, 물체가 약간 위치가 바뀌어도 모델이 같은 특징으로 인식하는 데 도움을 준다.

9. Stride와 Padding

Stride: 필터가 한 번에 이동하는 거리
크면 출력 크기가 더 작아짐
작으면 더 촘촘하게 봄

Padding: 입력 가장자리를 0 같은 값으로 채워 경계를 처리하는 방법
가장자리 정보 손실 완화/출력 크기 조절

10. 필터의 학습

필터 값은 처음에는 랜덤하게 시작하고, 학습(손실함수, 역전파, 옵티마이저)을 통해 최적화(점점 더 좋은 특징을 추출)된다.



>> 이미지를 평탄화하면 공간적 특징을 잃기 때문에 CNN에서는 합성곱 연산을 사용해 지역적 특징을 추출한다. 합성곱 결과 정보량이 많아질 수 있으므로 풀링을 통해 크기를 줄이고 중요한 정보만 남긴다. 이때 stride는 필터 이동 거리, padding은 경계 처리 방식이며, 필터는 학습을 통해 최적화된다.

[ CNN, RNN, LSTM ]

1. 개요

딥러닝 모델은 데이터의 형태에 따라 잘 맞는 구조가 달라.

CNN: 이미지처럼 공간적 구조가 중요한 데이터
RNN: 문장, 음성, 시계열처럼 순서가 중요한 데이터
LSTM: RNN의 한계를 보완한 모델로, 긴 순서 정보를 더 잘 기억해야 하는 데이터

이미지 → CNN**
순서 데이터 → RNN**
긴 순서 의존성 필요 → LSTM**

2. CNN (Convolutional Neural Network)

: 이미지의 공간적 특징을 추출하는 데 특화된 신경망

이미지는 픽셀들이 2차원 구조로 배치되어 있어서
단순히 평탄화해서 Dense layer에 넣으면 공간적 정보가 잘 보존되지 않는다.
그래서 CNN은 합성곱(Convolution)연산을 통해
가까운 픽셀들의 패턴을 잡아낸다.

> 이미지 전체를 한 번에 보지 않고,
작은 필터(filter) 를 이미지 위에 움직이면서
엣지, 선, 모서리, 질감 같은 지역적 특징(local feature) 을 추출한다.


1) Convolution Layer

필터를 적용해서 특징맵(feature map) 생성
이미지의 중요한 패턴 추출

2) Pooling Layer

정보 크기 축소
중요한 특징 요약
계산량 감소
이동에 대한 불변성 도움

3) Dense Layer

마지막에 추출된 특징을 바탕으로 최종 분류/예측 수행

장점)

이미지의 공간적 구조를 잘 반영
특징 추출을 자동으로 수행
이미지 분류, 객체 인식 등에 강함


단점)

순서 정보 처리에는 적합하지 않음
이미지처럼 격자 구조가 없는 데이터에는 비효율적일 수 있음

사용 분야:
이미지 분류, 얼굴 인식, 영상 처리, 의료영상 분석

= CNN은 합성곱 연산을 이용하여 이미지의 공간적 특징을 추출하는 데 특화된 신경망이다.

3. RNN (Recurrent Neural Network)

순서가 있는 데이터를 처리하기 위한 신경망

문장, 음성, 시계열 데이터는
앞에 나온 정보가 뒤의 해석에 영향을 주기 때문에
입력을 독립적으로 보면 안 된다.
RNN은 이전 시점의 정보를 은닉 상태(hidden state)로 저장하면서
순차적으로 데이터를 처리한다.
현재 입력만 보는 것이 아니라, 이전 시점의 정보도 함께 고려한다.


> 시간 순서대로 데이터를 하나씩 입력받고,
이전 hidden state와 현재 입력을 함께 사용해
새로운 hidden state를 만든다.
= 과거 정보가 다음 계산에 계속 전달된다



장) 순서 정보 반영 가능
문장, 음성, 시계열처럼 시간 흐름이 중요한 데이터에 적합

단)
긴 시퀀스를 다룰 때 오래전 정보를 잘 기억하지 못함
Gradient Vanishing / Exploding 문제가 생기기 쉬움
병렬 처리가 어려워 학습이 느릴 수 있음

사용 분야: 문장 처리, 번역, 음성 인식, 시계열(주가, 센서, 날씨) 예측

= RNN은 이전 시점의 정보를 은닉 상태로 유지하며 순서가 있는 데이터를 처리하는 신경망



4. LSTM (Long Short-Term Memory)

RNN의 장기 의존성 문제를 해결하기 위해 만든 개선된 순환 신경망

RNN은 앞의 정보를 뒤까지 오래 전달하는 데 한계가 있는데, (문장이 길어지거나 시계열이 길어지면 처음 정보가 뒤로 갈수록 희미해질 수 있음)
LSTM은 이를 보완하기 위해 셀 상태(cell state)와 게이트(gate) 구조를 사용한다.


>중요한 정보는 남기고,
불필요한 정보는 버리도록 **게이트**가 조절한다.


1) Forget Gate
이전 정보 중 무엇을 버릴지 결정

2) Input Gate
새로운 정보 중 무엇을 저장할지 결정

3) Output Gate
현재 상태에서 무엇을 출력할지 결정

장) 긴 문맥, 긴 시계열 정보 기억에 유리
RNN보다 장기 의존성 문제 완화
긴 문장 처리나 장기 패턴 예측에 강함

단)
구조가 복잡함
계산량이 많음
학습 속도가 느릴 수 있음

사용 분야: 장문 텍스트 처리, 긴 시계열 예측, 음성 처리, 자연어 처리

> LSTM은 셀 상태와 게이트 구조를 이용해 RNN의 장기 의존성 문제를 개선한 순환 신경망이다.

-
차이점)

CNN> 가까운 픽셀들의 모양과 패턴을 본다

RNN> 앞에서 본 내용을 기억하면서 다음 데이터를 본다

LSTM> RNN보다 더 오래 기억할 수 있게 만든다

CNN vs Dense

Dense는 평탄화해서 공간 정보 손실 가능
CNN은 공간 구조 유지하며 특징 추출 가능

RNN vs CNN

CNN은 공간 구조
RNN은 순서 구조

RNN vs LSTM

RNN은 긴 정보 기억이 약함
LSTM은 게이트 구조로 오래 기억 가능


결론 > 이미지는 공간적 특징이 중요하므로 CNN을 사용하고, 문장이나 시계열처럼 순서가 중요한 데이터는 RNN을 사용한다. 그러나 RNN은 긴 시퀀스에서 정보가 소실될 수 있으므로 이를 보완하기 위해 LSTM을 사용한다
